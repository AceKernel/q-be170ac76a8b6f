# Course notation and answer conventions

| Item | Convention |
|---|---|
| $S_t^{A/B}$ | Units of numerator currency $A$ per denominator currency $B$ |
| Bloomberg AB | Units of B per A, unlike the written fraction $A/B$ |
| $F_{0,T}$ | Forward rate agreed at 0 for delivery at $T$ |
| $X,C_T,P_T$ | Option strike; call/put payoff at expiry |
| $\pi,i,r$ | Inflation; nominal interest; real interest (define any case-specific reuse) |
| $R_D,R_F,R_{FX}$ | Home return; foreign-asset return; foreign currency's home-currency return |
| $\sigma,\rho,\beta$ | Standard deviation; correlation; systematic-risk coefficient |
| $D,E,V,\tau$ | Debt; equity; total market value; tax rate, in WACC contexts |
| $FCF,NPV,APV$ | Free cash flow; net present value; adjusted present value |
| PDF page | One-based physical page, not necessarily the printed slide label |

The same letter may serve different purposes in different lectures. Define it locally rather than mixing contexts. Keep currency units on each conversion and identify whether a percentage is annual, period or cumulative. Use decimals in products, then label final percentages. Retain unrounded intermediate values and round the final amount/rate sensibly.

For a calculation, a concise exam-style answer normally contains the exposure/assumption, formula, substitution, result with units and one sentence interpreting it. For a conceptual answer, connect the named course mechanism to the specific firm/event; do not pad with unrelated definitions. Show enough working for method marks. Supplementary references are not official model answers or a guarantee of marks.

Use LaTeX for mathematics. [Graph conventions](GRAPH-STYLE.md) distinguish derivative payoff, net profit and a hedged underlying cash flow. When data are absent or the source is inconsistent, state the limitation; do not silently invent a correlation, pro forma, premium date or funding rate.
